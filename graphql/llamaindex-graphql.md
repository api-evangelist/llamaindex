# LlamaIndex GraphQL API

LlamaIndex is a data framework for LLM applications. The LlamaCloud API covers managed ingestion pipelines, index management, document processing, retrieval, and chat agent endpoints for RAG applications.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from LlamaIndex REST/gRPC API
**Documentation:** https://developers.api.llamaindex.ai/
